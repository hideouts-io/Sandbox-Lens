# Sandbox Lens v0.1.1

October 7, 2026.

This update applies the approved Profile Print identity to the macOS app and repository. Sandbox policy scanning, comparison behavior, and the bundled reference catalog remain unchanged.

## Changes

- New macOS app icon with the approved logo and a pale contrast field.
- The overview and initial welcome view display the original-color bundled mark.
- Light and dark README headers, repository banners, and social-preview artwork.
- A refreshed overview screenshot from the branded app.

## Verified for this release

- 21 Swift tests and 2 Python generator tests pass.
- Repository-integrity and shell-syntax checks pass.
- The universal archive contains arm64 and x86_64 slices targeting macOS 13.0 or later.
- The staged and re-extracted apps pass strict code-signature verification and version/build checks.
- The compiled asset catalog resolves the app mark by name at both macOS image scales.
- Icon and logo source images match the approved branding exports exactly.
- The real branded app was inspected on macOS 27.0 (26A428); its exact-build scan read 610 profiles and reported 610 matches.

## Distribution note

This build is ad-hoc signed with Hardened Runtime. It is not Developer ID signed or notarized. Verify the accompanying `SHA256SUMS.txt` before opening it. See [Signing and distribution](https://github.com/hideouts-io/Sandbox-Lens/blob/v0.1.1/docs/SIGNING.md) for verification commands and the Gatekeeper limitations.

## Important limitations

Baseline coverage is incomplete, and static policy files cannot establish runtime use or compromise. A non-match is a review finding, not a malware verdict. Match the exact macOS product version and build before interpreting a difference.

The publication workflow adds the generated archive's exact SHA-256 value to these notes. The same value is provided in the attached `SHA256SUMS.txt` file.
